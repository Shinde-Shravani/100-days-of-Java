# ☕ 130 Days of Core Java

A structured **130-day Core Java learning journey** focused on building strong Java fundamentals, mastering Object-Oriented Programming, Collections, Java 8 features, Multithreading, File Handling, JDBC, and Advanced Core Java.

The goal is to **learn → code → practice → revise → build projects** consistently.

---

## 🎯 Goals

* Build a strong foundation in Core Java
* Strengthen problem-solving and coding skills
* Master Object-Oriented Programming
* Learn Java Collections Framework
* Understand Generics and Java 8 features
* Learn Multithreading and File Handling
* Learn JDBC and database connectivity
* Understand JVM and Java memory concepts
* Prepare for Java technical interviews
* Build practical Java projects
* Maintain consistent GitHub coding practice
